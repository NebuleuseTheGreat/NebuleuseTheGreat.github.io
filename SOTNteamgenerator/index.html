📁 Comment importer les données ?

Créez un fichier texte (ex: players.txt) contenant les joueurs et leurs notes au format JSON strict. Exemple :

{
  "Joueur1": 8.5,
  "Joueur2": 6,
  "Joueur3": 7.5
}

⚙️ Comment ça marche ?

Le système utilise un algorithme "glouton". Il trie les joueurs par note, puis attribue chaque joueur à l'équipe qui a actuellement le score total le plus bas. Cela garantit un équilibre mathématique quasi-parfait entre les équipes.
