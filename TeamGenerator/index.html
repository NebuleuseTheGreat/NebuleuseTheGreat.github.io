📁 How to import data?

Create a text file (e.g.: players.txt) containing the players and their ratings in strict JSON format. Example:

{
  "Joueur1": 8.5,
  "Joueur2": 6,
  "Joueur3": 7.5
}

⚙️ How does it work?

The system uses a "greedy" algorithm. It sorts players by rating, then assigns each player to the team that currently has the lowest total score.
